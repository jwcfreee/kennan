PROJECT / 001

NANIK

AI Commerce Operations Platform

I designed and built NANIK as a production SaaS for e-commerce operations. It connects with Shopify, centralizes operational data, provides analytics and AI-assisted auditing, and uses a human-controlled Action Queue for reviewing recommendations before execution.

The project covers application architecture, authentication, workspace permissions, Shopify OAuth and synchronization, AI workflows, deployment and SaaS billing infrastructure.
